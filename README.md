## 📌 Introduction

**Rose App** is a frontend project designed to deliver a sleek and simplified user experience. It supports dark mode, responsive design for all devices, and secure file uploads.

-----

## ✨ Features

  - Responsive design with Tailwind CSS.
  - State and network data management using React Query.
  - Integration with ShadCN UI for reusable components.
  - Support for React Hook Form and Zod for form validation.
  - Elegant and customizable file upload experience.

-----

## 🤝 Contribution

This project was a collaborative team effort. My primary responsibilities and contributions included:

  - **Project Scaffolding & Core UI:** Initialized the Next.js project structure, configured the development environment, and set up the foundational UI components using ShadCN UI.
  - **User Registration:** Implemented the complete user registration flow, including form validation and state management.
  - **Product Filtering System:** Developed the filtering logic for occasions and price ranges to enhance product discovery.
  - **E-commerce Checkout Process:** Built the multi-step checkout page, covering shipping address forms and payment method selection.
  - **Dashboard UI Enhancements:** Implemented the second data row in the main overview dashboard, displaying key metrics.
  - **Occasion Management (CRUD):** Developed the full Create, Read, Update, and Delete (CRUD) functionality for occasions within the admin dashboard.
